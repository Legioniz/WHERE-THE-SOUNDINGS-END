# Boat Physics

> Project: WHERE THE SOUNDINGS END  
> Status: Working baseline  
> Owner: Project lead  
> Version: 0.1  
> Last reviewed: 2026-11-10

Start with a readable arcade-simulation model: forward acceleration, throttle target, reverse, drag, speed-dependent steering, angular velocity, current/wind influence, vessel load, and hull damage. Use a fixed physics timestep and simplified hull colliders. Collisions need clear feedback. Full hydrodynamics is out of scope unless a proven player-facing need exists.
