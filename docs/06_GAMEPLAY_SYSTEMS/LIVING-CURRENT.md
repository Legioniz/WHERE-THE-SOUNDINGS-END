# Living Current

> Project: WHERE THE SOUNDINGS END  
> Status: Working baseline  
> Owner: Project lead  
> Version: 0.1  
> Last reviewed: 2026-11-10

Fish availability changes through habitat suitability, migration, recruitment, fishing pressure, and disturbance. First implementation should simulate regional stock values, not every fish globally. Recovery must be understandable and must not permanently empty progression-critical waters after one mistake.
