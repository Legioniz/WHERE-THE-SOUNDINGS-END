# Development Roadmap

> Project: WHERE THE SOUNDINGS END  
> Status: Working baseline  
> Owner: Project lead  
> Version: 0.1  
> Last reviewed: 2026-11-10

1. Foundation: pin Unity/editor version, Git workflow, coding conventions, asset pipeline, license register, test hardware, save strategy.
2. Boat/world prototype: handling, camera, ocean, fog, lighting, collision, docking, time/weather.
3. Fishing/economy: one method, five species, regional habitat, cargo, market, fuel, repair, recovery.
4. Signature systems: Sounding Rig, signal profiles, acoustic events, ecological response, first threat.
5. Vertical slice: 45–90 minutes, one region, NPC arc, threat, quest, full audio/UI/save loop, performance/accessibility review.
6. Full production: scale content only after vertical-slice quality and throughput are proven.
7. Release readiness: content lock, regression, localization decision, builds, store material, licensing audit, backups.
Timeline is not a commitment; a first 20+ hour commercial game may take multiple years part-time.
