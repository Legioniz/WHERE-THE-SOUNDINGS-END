## Maritime mysteries collection

The research-inspired quest files are kept separately so each can be revised, tested, accepted, or rejected without rewriting the main story.

See [Maritime Mysteries — collection index](SIDE_QUESTS/MARITIME_MYSTERIES/README.md).

Each quest file contains a short lore entry, discovery hook, player activity, possible consequence/reward, trigger ideas, dependencies, and research/cultural notes. These are proposals, not approved content. Each quest must be checked against the World Bible, region design, NPC roster, gameplay-system specs, accessibility requirements, and production scope before implementation.
