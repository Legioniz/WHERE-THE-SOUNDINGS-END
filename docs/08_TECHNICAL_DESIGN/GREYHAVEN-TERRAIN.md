# Greyhaven Procedural Island Terrain

> Project: WHERE THE SOUNDINGS END  
> Status: Working technical baseline — Editor-generated greybox; Unity verification pending  
> Owner: Project lead  
> Version: 0.1  
> Last reviewed: 2026-11-12

## 1. Scope

This document specifies the procedural island landform used by the Greyhaven generated scene. It upgrades the existing blockout terrain without claiming that the six-region archipelago has final geography. Greyhaven remains the only authored island environment in the current generated-scene pipeline; the other named regions are not silently represented by invented island meshes.

The terrain is gameplay-scale prototype geometry, not calibrated real-world bathymetry or final environment art.

## 2. Shared deterministic profile

`GreyhavenTerrainProfile` is the single source of truth for the builder's shoreline and elevation sampling. It lives in the runtime World assembly so Edit Mode tests and the Editor builder exercise identical math.

The profile combines:
- a curved sheltered-bay shoreline with deterministic low-frequency and fine coastline variation;
- separate west headland, east ridge, inland spine and rear terrace elevation masses;
- broad, medium and fine Perlin displacement plus ridged detail;
- a smooth coastal elevation ramp that keeps beach shelves low while inland landforms rise;
- finite-value fallbacks and a bounded elevation output.

The values describe the Greyhaven greybox only. They must be tuned through Unity camera, boat-navigation and collision review before being treated as final level dimensions.

## 3. Generated mesh

The Editor builder creates one shared land mesh using a 144 × 96 quad grid over the existing Greyhaven footprint. The shoreline is sampled independently at each X column, so the seaward edge follows the irregular bay contour instead of terminating in a rectangular row.

Each grid vertex receives a world-space UV suitable for later tiled materials. Triangles are assigned to four submeshes using their average elevation, slope angle and distance from the shoreline:
1. Soil — the default weathered ground.
2. Sand — a shallow, low-slope coastal band.
3. Grass — elevated, relatively gentle ground.
4. Basalt — steep faces and the highest exposed rock.

The renderer uses the existing Greyhaven soil, sand, grass and basalt materials. The same combined mesh is assigned to one static MeshCollider, preserving a single continuous land collision surface. Sand is part of the terrain mesh rather than a row of floating rectangular beach blocks.

The higher-resolution mesh has approximately 14,065 vertices and 27,648 terrain triangles before outcrop geometry. This is a prototype target; profile performance in Unity on representative hardware before raising resolution further.

## 4. Geological silhouettes

The builder replaces smooth stretched-sphere outcrops with deterministic, irregular faceted basalt forms. These remain static scenery/collision props and do not imply destructible geology, erosion simulation or procedural runtime streaming.

Landmark placement, village positions, harbor dimensions, breakwater positions, camera framing, sea level, boat controls and the six-region scaffold remain unchanged in this pass.

## 5. Invariants and failure handling

- Shoreline and terrain samples are deterministic for the same Unity version and input coordinates.
- Invalid sample coordinates return finite safe fallbacks.
- Elevation is clamped to the configured profile bounds.
- Terrain surface classification handles invalid values by returning the default soil surface.
- All submeshes use the same vertex/index space and are covered by the single terrain collider.
- The terrain is generated by `GreyhavenEnvironmentBuilder`; generated scene edits must be made in the builder/profile, not as undocumented edits to generated scene output.
- No save schema, persisted ID, input action, sea clock, water-surface or survey contract changes.

## 6. Validation

Edit Mode tests cover shoreline determinism and envelope, distinct headland/inland elevations, bounded finite height samples, surface classification and invalid-value fallback.

After pulling the change, run **Tools > WHERE THE SOUNDINGS END > Rebuild Greyhaven Environment** in Unity `6000.3.28f1`. Then verify:
- no cracks or gaps along the shoreline or terrain submesh boundaries;
- correct beach, soil, grass and basalt reads at gameplay camera scale and under overcast lighting;
- lighthouse, village residents, buildings, roads, breakwater and NPC anchors sit on the updated terrain;
- the terrain collider remains continuous and the boat can approach/leave the harbor without catching on a mesh seam;
- collision against the new faceted outcrops is stable;
- terrain and outcrop rendering/collision cost remains acceptable.

Static repository checks and C# syntax checks do not prove Unity semantic compilation, Editor mesh generation, Play Mode collision behavior or a Windows player build. Those checks remain pending until run in the pinned Editor.
