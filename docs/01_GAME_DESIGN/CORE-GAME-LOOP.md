# Core Game Loop

> Project: WHERE THE SOUNDINGS END  
> Status: Working baseline  
> Owner: Project lead  
> Version: 0.1  
> Last reviewed: 2026-11-10

| Stage | Player action | System response | Decision |
|---|---|---|---|
| Prepare | Review weather, supplies, gear, rumours | Partial information from services and forecast | What risk is acceptable? |
| Depart | Launch and choose route | Boat, fuel, time, visibility matter | Direct or safer route? |
| Read | Observe water, sound, current, landmarks | Environmental cues update | Which cue is trustworthy? |
| Work | Fish, deploy rig, investigate | Catch and discovery resolve | Continue or retreat? |
| Escalate | React to weather, damage, threat | Threat/world state responds | Hide, reroute, return? |
| Return | Navigate to harbour | Travel and arrival condition resolve | Protect cargo or pursue more? |
| Reflect | Sell, repair, speak, catalogue | Economy, ecology, NPCs, story update | What does the evidence mean? |

Travel must provide navigation, discovery, risk, or atmosphere rather than empty padding.
