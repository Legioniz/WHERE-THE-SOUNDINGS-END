# Game Vision

> Project: WHERE THE SOUNDINGS END  
> Status: Working baseline  
> Owner: Project lead  
> Version: 0.1  
> Last reviewed: 2026-11-10

Create a memorable fishing horror game where the sea is both livelihood and mystery, and the player's ability to read it becomes their primary form of power. Each voyage must have practical purpose, curiosity, uncertainty, and risk. Fishing, sound, weather, visibility, ecology, and threats should form one connected system.
