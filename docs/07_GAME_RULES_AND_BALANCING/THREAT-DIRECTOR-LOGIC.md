# Threat Director Logic

> Project: WHERE THE SOUNDINGS END  
> Status: Working baseline  
> Owner: Project lead  
> Version: 0.1  
> Last reviewed: 2026-11-10

The director schedules opportunities; creatures own local perception and behavior. Inputs: region, time, weather, player noise, Sounding Rig use, damage, recent encounters, cooldowns, story gates, safe-zone exclusions. Maintain bounded tension; when thresholds are reached, select an eligible authored event using weights and cooldowns. Never teleport a threat into unavoidable attack range. Preserve warning/counterplay and quiet intervals; make player-caused escalation learnable.
